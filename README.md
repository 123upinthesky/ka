# Конкурентный анализ

Статический дашборд конкурентного анализа дилера Форсаж в сравнении с рынком и конкурентами.

## Что внутри

- вкладки по маркам автомобилей;
- распределение лидов по дилерам по месяцам;
- средняя стоимость лида с аукционом: рынок и дилер на одном графике;
- распределение объявлений по дилерам по месяцам;
- экспорт активной вкладки в PDF.

## Запуск

Откройте `index.html` напрямую в браузере. Отчет самодостаточный: данные, изображения и библиотеки для PDF лежат внутри папки проекта.

Также папку можно разместить на любом статическом хостинге без дополнительной серверной логики.
